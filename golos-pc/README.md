# Голосовой диалог с BF7 (ПК-часть)

Телефон пишет голос собеседника и проигрывает ответ в разговор
(`bf7-rech` «zapis»/«igraj», канал команд `bf7-zvonki`), а распознавание и
синтез идут здесь, на ПК: whisper.cpp на видеокарте и Piper.

- `podgotovit.sh` — скачать Piper (x86_64), голос `ru_RU-dmitri-medium`,
  модель whisper `large-v3-turbo-q5_0` и собрать whisper.cpp с CUDA.
- `sluh-pc` — во время разговора: включает запись собеседника на телефоне,
  тянет поток по SSH, режет на фразы по паузам и печатает распознанное
  строками «ЧЧ:ММ:СС СОБЕСЕДНИК: …» (и в `dialog.log`).
- `skazat-pc "текст"` — Piper → 48 кГц стерео → на телефон → в разговор.

На телефоне есть свой запасной путь без ПК: `bf7-sluh` (whisper.cpp на
процессоре) и `bf7-skazat` (Festival). Для разговора он не годится: на
Cortex-A53 whisper base-q5_1 распознаёт 4,6 с речи за 27,7 с, Piper говорит
в 1,8 раза медленнее реального времени. На ПК: 0,8 с на фразу и 0,4 с на
синтез 3,4 с речи.

`dialog-storozh` — ждёт звонка хозяина: трубку берёт телефон (служба
`bf7-hozyain`, только номер из `/etc/bf7/hozyain-nomer`), сторож здоровается,
включает `sluh-pc` и печатает реплики для Клауда; отвечать — `skazat-pc`.
